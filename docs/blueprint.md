# **App Name**: RentNode Kenya Lite

## Core Features:

- Property Listing: User-friendly interface for landlords to add and manage their rental properties.
- Property Display: Display property listings with key details and clear visuals for prospective tenants.
- Image Upload: Allow landlords to upload property images, enhancing listing attractiveness.
- AI Rental Analysis: AI tool suggests appropriate rental price based on location and property characteristics.
- Direct Messaging: Enable direct contact between landlords and tenants through the platform.

## Style Guidelines:

- Primary color: Muted blue (#5D9CFF) for trustworthiness and stability in financial management.
- Background color: Very light blue (#E0F7FA), providing a clean and unobtrusive backdrop.
- Accent color: Soft violet (#B282CE), to draw the eye and add a touch of elegance.
- Font: 'Inter', a sans-serif font, providing a clean and modern feel suitable for both headings and body text.
- Responsive design for access on various devices.
